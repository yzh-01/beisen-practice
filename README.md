# 北森测评练习

中文认知能力练习工具，排除性格、兴趣、价值观、动机等自陈问卷。默认使用 **117 道 GitHub 来源题，不抽原创题**。

## 使用

双击 `北森测评练习.html` 即可使用。约 1.5 MB 的单文件包含脚本、样式、题库和 66 张原题图片，无需安装依赖或联网。来源链接需要联网。

选择模块、题量、难度和来源。默认“即时反馈”：选中答案即提交本题，立即显示对错、正确答案与解析，并锁定答案，读完后点击“下一题”。“手动核对”允许选好后再点击核对；“限时模拟”在交卷后统一显示答案，超时自动提交。完成后显示分数、正确率、完成率、题型表现、解题解析及练习建议。支持题图放大、答题卡、标记、当前会话错题重练和 JSON 报告导出。

成绩与错题在当前页面会话中保留，刷新后清空；需要保存时请导出报告。

## 计分

每题等权；分数 = 答对题数 ÷ 总题数 × 100。答错、未答不得分，不倒扣。正确率采用相同分母，另列已答题正确率和完成率。

分数反映本组练习表现，不等同于北森 CATA 的 IRT 能力值、百分位或通过线。题量较少的模块会提示先增加样本。

## 本地开发与维护

源码入口 `dist/index.html`，无第三方前端依赖。可运行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist` 进行本机预览。

原有题库为 `dist/bank.js`，GitHub 题库为 `dist/github-bank.js`，图片为 `dist/question-bank/`。`scripts/import-github.cjs` 读取已下载的 JSON 数据行，不执行仓库代码；筛选与解析记录在 `research/`。调整题库后运行：

```text
node scripts/import-github.cjs
node scripts/make-offline.cjs
node scripts/validate.cjs
```

结构、来源固定提交、原图字节、选项范围、漏答计分、均衡抽题及离线内嵌资源均有检查。公式/规则题使用计算和枚举复核；阅读与论证题按题干人工审阅。浏览器验证记录见 `VALIDATION.md`。

克隆仓库后可直接运行 `node scripts/validate.cjs` 和使用现成的离线文件，不依赖原始资料快照。原始仓库与完整 OCR 草稿不提交；若要重新导入题库，将 BeiSen_Practice 指定提交的源码解压到 `research/upstream/BeiSen_Practice-fcd30068e84421a97f1aca6ab98b1f1400e11406/` 后再运行导入脚本。有该快照时验证会额外对比原题行号与图片字节。

题库仓库的内容与代码许可应分别核对；未提供许可证的资料不视为官方授权或允许任意再发布。项目保存于私有 GitHub 仓库 [yzh-01/beisen-practice](https://github.com/yzh-01/beisen-practice)，站点使用 Sites 托管并保留仅本人可访问的权限；离线版本仍可直接使用。

页面在支持 WebMCP 的浏览器中提供配置练习、读取已提交成绩两个工具，普通浏览器使用不受影响。
